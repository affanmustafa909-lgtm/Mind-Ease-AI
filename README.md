# Mind Ease AI

Mind Ease AI is an AI-powered mental wellness support system developed using C# in Visual Studio and MySQL database. The system is designed to help users manage stress, anxiety, and emotional challenges through intelligent conversation, mood tracking, and emotional analysis.

---

# Features

- AI Chat Support
- Mood Tracking System
- Sentiment Analysis
- Mental Wellness Tips
- Relaxation Exercises
- Daily Check-ins
- Personalized Recommendations
- Secure User Privacy
- Responsive User Interface
- Crisis Detection Support
